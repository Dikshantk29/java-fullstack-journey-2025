
## 1. Array

**Definition:**
An Array is a linear data structure that stores elements of the same data type in contiguous memory locations and allows direct access using an index.

**Real-World Example:**
Seats in a cinema hall arranged row-wise. Each seat has a fixed position number, and you can directly access seat 15 without checking others.

---

## 2. String

**Definition:**
A String is a sequence of characters stored contiguously and treated as a single data type in most programming languages.

**Real-World Example:**
A person’s name on an Aadhaar card—characters in a fixed order forming meaningful information.

---

## 3. Linked List

**Definition:**
A Linked List is a linear data structure where elements are stored in nodes, and each node contains data and a reference to the next node.

**Real-World Example:**
A train where each coach knows only the next coach. You must move step by step to reach a specific coach.

---

## 4. Stack

**Definition:**
A Stack is a linear data structure that follows **LIFO (Last In, First Out)** principle.

**Real-World Example:**
A stack of plates in a cafeteria. The last plate placed is the first one removed.

---

## 5. Queue

**Definition:**
A Queue is a linear data structure that follows **FIFO (First In, First Out)** principle.

**Real-World Example:**
People standing in line at a bank counter. The first person in line is served first.

---

## 6. Deque (Double Ended Queue)

**Definition:**
A Deque is a queue-like data structure where insertion and deletion can occur at both ends.

**Real-World Example:**
A train platform where passengers can enter or exit from both front and rear doors.

---

## 7. Priority Queue

**Definition:**
A Priority Queue is a special queue where elements are processed based on priority rather than insertion order.

**Real-World Example:**
Hospital emergency room. Patients with critical conditions are treated before others.

---

## 8. Hash Table (Hash Map)

**Definition:**
A Hash Table stores data in key–value pairs and uses a hash function to provide fast insertion, deletion, and search.

**Real-World Example:**
A phone contact list. You search a name (key) to directly get a phone number (value).

---

## 9. Set

**Definition:**
A Set is a data structure that stores unique elements and does not allow duplicates.

**Real-World Example:**
A collection of Aadhaar numbers—each number must be unique.

---

## 10. Tree

**Definition:**
A Tree is a hierarchical, non-linear data structure consisting of nodes connected by edges, with one root node.

**Real-World Example:**
Company organizational structure—CEO at the top, managers below, employees under managers.

---

## 11. Binary Tree

**Definition:**
A Binary Tree is a tree data structure in which each node has at most two children.

**Real-World Example:**
A decision tree where each question leads to two possible choices (yes/no).

---

## 12. Binary Search Tree (BST)

**Definition:**
A BST is a binary tree where the left subtree contains values smaller than the node and the right subtree contains larger values.

**Real-World Example:**
A dictionary where words are arranged in alphabetical order for faster search.

---

## 13. Heap

**Definition:**
A Heap is a complete binary tree that satisfies the heap property (min-heap or max-heap).

**Real-World Example:**
A task scheduler in an OS where the highest-priority task gets CPU time first.

---

## 14. Graph

**Definition:**
A Graph is a non-linear data structure consisting of vertices (nodes) and edges representing connections between them.

**Real-World Example:**
Google Maps—cities are vertices, roads are edges.

---

## 15. Trie

**Definition:**
A Trie is a tree-based data structure used to store strings efficiently, especially for prefix searching.

**Real-World Example:**
Autocomplete suggestions in a search engine.

---

## 16. Matrix

**Definition:**
A Matrix is a two-dimensional array organized into rows and columns.

**Real-World Example:**
An Excel spreadsheet with rows and columns.

---

## 17. Disjoint Set (Union-Find)

**Definition:**
A Disjoint Set is a data structure used to manage a collection of non-overlapping sets with union and find operations.

**Real-World Example:**
Social networks grouping users into different connected communities.

---

## 18. Segment Tree

**Definition:**
A Segment Tree is a tree data structure used for efficient range queries and updates on an array.

**Real-World Example:**
Checking total sales between day 10 and day 30 from a large sales report.

---

## 19. B-Tree

**Definition:**
A B-Tree is a self-balancing tree data structure optimized for systems that read/write large blocks of data.

**Real-World Example:**
Database indexing in systems like MySQL or Oracle.

---

## 20. Graph Adjacency List / Matrix

**Definition:**
These are representations of graphs using either lists (space-efficient) or matrices (fast access).

**Real-World Example:**
Railway connections stored as stations with linked routes (list) or distance tables (matrix).

---
